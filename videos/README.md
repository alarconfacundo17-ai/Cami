# Videos del canal

Cada carpeta tiene el script que arma un video a partir de las imágenes y la voz generadas en Buzzy.

- `ruta40/build.py`: historia de terror "Ruta 40" (31 s). Usa r1–r6.png (imágenes), r2_off.png (espejo con luces apagadas) y voz.mp3 (voz de Marcelo, ElevenLabs). Agrega pausas a la voz, cortes con zoom, subtítulos palabra por palabra y sonido de suspenso.

Las imágenes y audios no se suben al repo; se bajan de Buzzy.
